ENTROPY / MANUAL SETUP

Your results dashboard.
Two files. Your Google account.

Copy the bundled dashboard into a new standalone Apps Script project and deploy it from the browser.

This page is a local installation guide. The connected dashboard runs on Google after you deploy it.

1Choose the Google account

Sign in with the account that should own the dashboard. First confirm it can open your Figures folder. With several Google accounts, use a dedicated browser profile or private window signed in only to that account.

Check access to Figures ↗Open Apps Script ↗

Choose New project and name it Entropy Results Dashboard. Start with a new project so the bundled functions have no duplicates.

2Paste the dashboard code

In the new project, open Code.gs. Select all its existing contents and replace them with the code below. The complete interface and server are included in this one file.

Save source file

View the bundled code

3Paste the manifest

Open Project Settings (the gear icon) and enable Show appsscript.json manifest file in editor. Return to the editor, open appsscript.json, and replace its contents with this manifest. Save the project.

Save manifest

View the manifest

The manifest enables Drive API v3. If Drive does not appear under Services, use its + button to add Drive API, version v3.

4Authorize and initialize

Select setup in the function dropdown at the top of the editor, then click Run. Complete Google's authorization flow for your own project. Setup checks access to Figures, starts the catalog, and installs automatic refresh.

The first scan can continue across several batches. If setup reports a folder-access error, confirm that this Google account can open Figures before deploying.

5Deploy the web app

Choose Deploy → New deployment, select Web app as the type, and use these settings:

Execute as
Me
Who has access
Only myself

Click Deploy. Copy the Web app URL ending in /exec and open it using this same Google account.

Bookmark the new URL. If the catalog is still scanning, choose Resume index in the dashboard. The refresh trigger also continues the scan in the background.

Keep it easy to find

You can keep the standalone project in your own Drive. Opening the project shows the code editor. Use a bookmark or update the existing launch document with your new /exec URL to open the dashboard.

The previous launch document still points to the earlier deployment until you replace its link. Uploading these files to an ordinary Drive folder stores them; the steps above create the running app.
